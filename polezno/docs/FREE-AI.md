# Бесплатный внешний ИИ: OpenRouter

Выбран внешний сервис OpenRouter и модель apodex/apodex-1.1-mini:free. Локальные модели и Ollama не устанавливались.

## Действия владельца

1. Откройте https://openrouter.ai/settings/keys и войдите в свой аккаунт.
2. Создайте API-ключ для Polezno. Для выбранного бесплатного режима пополнение баланса не планируется.
3. В локальном .env сохраните ключ после LLM_API_KEY=. Не отправляйте ключ в переписку и не включайте .env в архив.
4. Напишите исполнителю, что файл сохранён. Сначала выполняется один технический API-тест, затем перезапуск бота и проверка общего справочного вопроса со второго аккаунта.

Остальные настройки в локальном .env уже заполнены:

    LLM_PROVIDER=openrouter-free
    LLM_BASE_URL=https://openrouter.ai/api/v1
    LLM_MODEL=apodex/apodex-1.1-mini:free
    LLM_TIMEOUT_MS=40000

Без ключа бот продолжает извлекать справку из локальной базы. Название модели в настройках не означает, что реальный вызов проверен.

## Проверка подключения

Команда без --live проверяет настройки без сети:

    node --env-file=.env scripts/check-llm.ts

Один технический запрос, без истории пользователей/Telegram IDs/файлов/медицинских сведений:

    node --env-file=.env scripts/check-llm.ts --live

Успех: ok=true, code=validated_answer. Не требуется отправлять пользователю медицинский вопрос для проверки ключа.

Диагностика: missing_key, invalid_key, access_denied, quota_or_balance, rate_limit, model_or_route_unavailable, provider_unavailable, network_or_timeout, invalid_answer. Значения ключей и сырые сообщения ошибок провайдера не печатаются. Неудача не вызывает платный повторный запрос.

## Ограничения бесплатного подключения

- Принимаются только явно указанные модели с суффиксом :free и официальный endpoint OpenRouter.
- В каждом запросе provider.max_price задаёт prompt=0, completion=0, request=0; платный резервный список моделей отсутствует.
- Требуются поддержка параметров, data_collection=deny и zdr=true. Apodex/Novita принимает json_object; ответ строго проверяется локально, включая обязательные поля, допустимые действия и IDs источников/товаров. Для остальных моделей запрашивается JSON Schema. Если подходящего бесплатного маршрута нет, приложение сообщает о невозможности подготовить ответ; эти ограничения не ослабляются автоматически.
- Это параметры маршрутизации OpenRouter, а не независимая гарантия соблюдения политик сторонним провайдером.
- Наличие, квоты и поддержка JSON Schema у бесплатных моделей могут изменяться. Маршрут Apodex/Novita проверен реальным ключом с этими фильтрами и нулевым лимитом ключа.
- Нет обещания неограниченного бесплатного облачного сервиса. При превышении лимита сохраняются очередь врачей и локальная история; пользователю предлагается повторить запрос или обратиться к врачу.
- Передаются тексты текущего разговора после маскировки явных контактов и найденные справочные фрагменты. Файлы и поля Telegram-профиля в модель не передаются. Полное обезличивание свободного текста не гарантируется.
- Модель не заменяет согласованные материалы, действующих врачей и проверку качества ответов.

## Фактическое подключение — 11.10.2026

- Ключ Polezno создан в аккаунте владельца, сохранён только в локальном .env; расходный лимит $0, истекает 09.01.2027.
- NVIDIA отклонена маршрутизацией по политике данных. Apodex объявляет structured_outputs в каталоге, но реальный endpoint возвращает 400 для json_schema; совместимость подтверждена для json_object.
- Первые ответы Apodex были нестабильны; уточнён JSON-контракт и выбор action в системной инструкции, температура 0. После изменения технический проверочный код и общий вопрос о пищевых добавках дали валидные ответы с правильными sourceIds.
- Первоначально проверены подключение и два сценария; позже семь приёмочных сценариев прошли с реальным API (четыре вызова модели). Это не клиническая оценка качества. Невалидные ответы блокируются и заменяются предложением уточнить вопрос/обратиться к врачу.
- Telegram-процесс перезапущен с openrouter-free, /ready=ok, failedDeliveries=0. Владелец подтвердил, что ответы внешнего ИИ в Telegram работают; агрегаты БД подтвердили два завершённых задания ИИ и два сообщения assistant без чтения их содержимого.

- Вводный мастер OpenRouter автоматически создал дополнительный Default key с лимитом $100. Он отключён; состояние подтверждено действием Enable в меню. Бот использует только отдельный ключ Polezno с лимитом $0; платёжные данные не добавлялись.
